# План разработки Telegram-бота для генерации LegalTech-планов через Claude API

## 1. Общее описание

### 1.1 Цель
Создать Telegram-бота, который принимает от пользователя идею/тезисы и с помощью Claude API генерирует структурированный план проекта LegalTech с актуальными практиками 2024-2026, включая календарные мероприятия.

### 1.2 Границы MVP
MVP включает генерацию плана и базовые команды. MCP-интеграции, deep research, экспорт и расширенные интеграции выносятся в пост-MVP.

| Компонент | Технология | Версия | Назначение |

- Telegram: лимит 4096 символов на сообщение, нужен разрез на чанки
- Форматирование: использовать MarkdownV2 или HTML и экранировать
- Claude API: таймауты и ретраи с экспоненциальным бэкофом

## 5. Обработчики

### 5.1 start.py
- /start, /help, /examples
- Краткая инструкция и примеры

### 5.2 plan.py (основная логика)

Алгоритм:
```
1. Получить сообщение пользователя
2. Валидация входных данных
   - длина 10-4000 символов
   - фильтр мусора/спама
3. Отправить индикатор "печатает..."
4. Сформировать запрос к Claude API
   - системный промпт
   - сообщение пользователя
5. Получить ответ от Claude
6. Обработать ответ
   - базовая валидация структуры
7. Подготовить ответ к отправке
   - экранирование Markdown
   - разбиение на чанки <= 4096 символов
8. Отправить результат пользователю
```

Ошибки:
- Таймаут API → повторный запрос (max 2 попытки, экспоненциальный бэкоф)
- Rate limit → сообщение пользователю
- Невалидный ответ → fallback на базовый шаблон
- Любая ошибка → логируем код и контекст без пользовательского текста
